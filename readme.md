*This is a homework project for the course Introduction to Numerical Algorithms by Papp Mátyás and Sinóros-Szabó Zsombor.*

The project aims to create a well-detailed visualization of the fast Fourier transform using a 2D canvas on which rotating arrows are used to draw an arbitrary complex function. This complex function can represent a simple drawing, therefore, the rotating arrows can draw almost any 2D shape that the user defines.

As the fast Fourier transform is well implemented in Python and other programming languages, we aim to recreate the algorithm from scratch and detail the project so that the visual UI is pleasing to look at.
